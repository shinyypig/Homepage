# 奇思妙想

这里记录一些零散的想法和灵感，或许未来会成为有趣的项目或文章。

## 想法列表

1.  **利用大语言模型挖掘历史中的趣事**：最近在看《南明史》，作者顾诚为了搜集材料，每日都需要去图书馆进行摘录，一天也就几页稿纸。想象一下，在历史文献数字化的今天，是否可以利用大语言模型来挖掘历史中的趣事和细节？这远超人类的综合检索能力，或许能发现一些有趣的历史片段。

2.  **四维图片预测婴儿长相**：刚给六个月大的，还在肚子里的宝宝拍了四维彩超照片。尝试用 GPT5 预测一下宝宝的长相，没想到违规了，不让生成（风控真是严格啊）。转而使用 Nano Banana 生成了一下，感觉还行。如果能搜集到更多四维彩超照片和对应的宝宝照片，或许可以训练一个模型来预测婴儿的长相，市场潜力巨大（或许吧）。

3.  **本科生毕业论文写作平台**：给本科生改论文简直是酷刑，不过好在今年用上了我自己写的 LaTeX 模版，省了不少事。想开发一个本科生毕业论文写作平台，集成 LaTeX 模版、参考文献管理、在线协作等功能，并且接入大语言模型。让大语言模型检查语法、格式，甚至提供写作建议，这样产出的论文想必质量要高一个台阶（至少格式不会错）。
